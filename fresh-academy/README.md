# NDT Masterclass Academy — Independent Website

This is a fresh, standalone static website in `fresh-academy/`. It does not route lesson buttons into the legacy application.

## Included
- Responsive maroon, burnt-orange and white interface
- Eight NDT method syllabus pages
- Direct lesson navigation using URL hashes (refresh-safe)
- Lesson completion and progress dashboard saved in browser localStorage
- Formula library with working calculators
- 25-question practice sessions, answer navigation, explanations and local history
- Learner profile display name saved locally
- Educational disclaimer: this platform is not an ASNT, ISO 9712, Level II/III or other personnel certification body

## Preview / GitHub Pages
Once this folder is merged into `main` and GitHub Pages serves the repository root, open:
`https://rahulk2oo4.github.io/ut-masterclass-academy-NDT/fresh-academy/`

If Pages is configured to publish from a different folder or deployment workflow, adjust the Pages source accordingly.

## Current limitations
This standalone first build uses browser-local storage and does not yet integrate Supabase authentication/cloud sync. Lesson content is original introductory material and should be expanded and reviewed before use as a complete technical curriculum. Formula examples are educational; validate all assumptions and units against applicable procedures and standards. Formal 100-question examinations and certificates are not included in this standalone build.
